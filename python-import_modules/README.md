# 0x02. Python - import & modules

- `0-add.py`: imports `add` from `add_0` and prints `1 + 2 = 3`.
- `1-calculation.py`: imports the calculator functions from `calculator_1` and prints add/sub/mul/div of 10 and 5.
- `2-args.py`: prints the number of arguments and the list of them.
- `3-infinite_add.py`: prints the sum of all arguments.
- `4-hidden_discovery.py`: prints the names defined by `hidden_4.pyc` that don't start with `__`, in alphabetical order.
- `5-variable_load.py`: imports the variable `a` from `variable_load_5` and prints it.
- `100-my_calculator.py`: basic calculator using the functions in `calculator_1`.
- `101-easy_print.py`: prints `#pythoniscool` without using `print`.
- `102-magic_calculation.py`: function equivalent to the given bytecode.
- `103-fast_alphabet.py`: prints the uppercase alphabet in 3 lines without loops or string literals.
