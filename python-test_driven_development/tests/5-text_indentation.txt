The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

The function does not print a final new line, so each example below
adds a print() to end the output:

A text with the three special characters:

    >>> text_indentation("Hello. How are you? Fine: thanks"); print()
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

A text without special characters:

    >>> text_indentation("Hello World"); print()
    Hello World

Spaces at the beginning and at the end of the lines are removed:

    >>> text_indentation("   Hello.    World   "); print()
    Hello.
    <BLANKLINE>
    World

A text ending with a special character:

    >>> text_indentation("Bye."); print()
    Bye.
    <BLANKLINE>
    <BLANKLINE>

Special characters in a row:

    >>> text_indentation("What?? Really."); print()
    What?
    <BLANKLINE>
    ?
    <BLANKLINE>
    Really.
    <BLANKLINE>
    <BLANKLINE>

An empty text:

    >>> text_indentation(""); print()
    <BLANKLINE>

The text is not a string:

    >>> text_indentation(12)
    Traceback (most recent call last):
    TypeError: text must be a string

    >>> text_indentation(None)
    Traceback (most recent call last):
    TypeError: text must be a string

    >>> text_indentation(["Hello."])
    Traceback (most recent call last):
    TypeError: text must be a string

A missing argument:

    >>> text_indentation()
    Traceback (most recent call last):
    TypeError: text_indentation() missing 1 required positional argument: 'text'
