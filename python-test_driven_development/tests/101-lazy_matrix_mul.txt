The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

This function uses NumPy, so the exceptions are the ones raised by NumPy.
The type of some of them (TypeError or ValueError) and all the messages
depend on the NumPy version, so the tests below check the exception type
and print only the name of the exception.

Import the function:

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Two square matrices:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

Matrices with different shapes:

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1], [2], [3]], [[4, 5]]))
    [[ 4  5]
     [ 8 10]
     [12 15]]

Floats:

    >>> print(lazy_matrix_mul([[1.5, 2]], [[2], [0.5]]))
    [[4.]]

The matrices are not changed:

    >>> a = [[1, 2], [3, 4]]
    >>> b = [[0, 1], [1, 0]]
    >>> print(lazy_matrix_mul(a, b))
    [[2 1]
     [4 3]]
    >>> a, b
    ([[1, 2], [3, 4]], [[0, 1], [1, 0]])
