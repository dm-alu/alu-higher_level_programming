The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

This function uses NumPy, so its exceptions are the ones raised by NumPy
and they depend on the NumPy version. To keep the tests exact with any
version, each case compares the result (or the exception type and message)
of ``lazy_matrix_mul`` with the one of ``numpy.matmul``.

Import the function and NumPy, and define the helpers:

    >>> import numpy
    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul
    >>> def outcome(function, *args):
    ...     try:
    ...         return ("value", repr(function(*args)))
    ...     except Exception as e:
    ...         return ("error", type(e).__name__, str(e))
    >>> def same_as_numpy(*args):
    ...     return outcome(lazy_matrix_mul, *args) == outcome(numpy.matmul, *args)

Two square matrices:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

Matrices with different shapes:

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1], [2], [3]], [[4, 5]]))
    [[ 4  5]
     [ 8 10]
     [12 15]]

Floats:

    >>> print(lazy_matrix_mul([[1.5, 2]], [[2], [0.5]]))
    [[4.]]

The matrices are not changed:

    >>> a = [[1, 2], [3, 4]]
    >>> b = [[0, 1], [1, 0]]
    >>> print(lazy_matrix_mul(a, b))
    [[2 1]
     [4 3]]
    >>> a, b
    ([[1, 2], [3, 4]], [[0, 1], [1, 0]])

The first matrix is a string:

    >>> outcome(lazy_matrix_mul, "hello", [[1, 2], [3, 4]])[0]
    'error'
    >>> same_as_numpy("hello", [[1, 2], [3, 4]])
    True

The second matrix is a string:

    >>> outcome(lazy_matrix_mul, [[1, 2], [3, 4]], "hello")[0]
    'error'
    >>> same_as_numpy([[1, 2], [3, 4]], "hello")
    True

The first matrix is not a list of lists:

    True

The second matrix is not a list of lists:

    >>> same_as_numpy([[1, 2]], [1, 2, 3])

    >>> outcome(lazy_matrix_mul, [[1, "a"], [3, 4]], [[1, 2], [3, 4]])[0]

    >>> same_as_numpy([[1, "a"], [3, 4]], [[1, 2], [3, 4]])

The second matrix contains something else than numbers:

The first matrix is not a rectangle:

    >>> same_as_numpy([[1, 2], [3]], [[1, 2], [3, 4]])
    True

The second matrix is not a rectangle:

    >>> same_as_numpy([[1, 2], [3, 4]], [[1, 2], [3]])

The matrices can't be multiplied:

    >>> outcome(lazy_matrix_mul, [[1, 2]], [[1, 2]])[:2]
    ('error', 'ValueError')
    >>> same_as_numpy([[1, 2]], [[1, 2]])
    True

    True
