The ``101-lazy_matrix_mul`` module
==================================

Using ``lazy_matrix_mul``
-------------------------

Import the function:

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Two square matrices:

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

Matrices with different shapes:

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1], [2], [3]], [[4, 5]]))
    [[ 4  5]
     [ 8 10]
     [12 15]]

Floats:

    >>> print(lazy_matrix_mul([[1.5, 2]], [[2], [0.5]]))
    [[4.]]

The matrices can't be multiplied (the message depends on the NumPy version):

    >>> lazy_matrix_mul([[1, 2]], [[1, 2]])  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    ValueError: shapes not aligned

    >>> lazy_matrix_mul([[1, 2, 3], [4, 5, 6]], [[1, 2], [3, 4]])  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    ValueError: shapes not aligned

    ValueError: shapes not aligned
