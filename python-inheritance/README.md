# 0x0A. Python - Inheritance

- `0-lookup.py`: list the attributes and methods of an object.
- `1-my_list.py`: `MyList`, a list that can print itself sorted.
- `2-is_same_class.py`: exact class check.
- `3-is_kind_of_class.py`: instance or subclass check.
- `4-inherits_from.py`: strict subclass check.
- `5-base_geometry.py` to `7-base_geometry.py`: `BaseGeometry` with
  `area` and `integer_validator`.
- `8-rectangle.py`, `9-rectangle.py`: `Rectangle` based on `BaseGeometry`.
- `10-square.py`, `11-square.py`: `Square` based on `Rectangle`.
- `tests/`: doctest files, run with `python3 -m doctest ./tests/*`.
